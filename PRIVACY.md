# Privacy Policy — LAIF

_Last updated: 2026-11-12_

LAIF ("the app") is a personal, single-user application operated by its owner and
run locally on the owner's own computer. It is not a public service.

## Data the app accesses

With the owner's explicit Google authorization, LAIF uses the Google Calendar API
to:

- read the owner's own calendar events, and
- create new calendar events on the owner's behalf.

## How the data is used

Calendar data is used solely to provide the owner's own scheduling features. All
processing happens locally on the owner's machine.

## Data sharing

LAIF does not share, sell, or transmit the owner's data to any third party. No
data is sent to external servers other than the Google APIs strictly required to
provide the functionality above.

## Data storage and retention

Data is stored locally on the owner's device and can be deleted by the owner at
any time. Authorization tokens are stored in the operating system keychain.

## Limited Use

LAIF's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
