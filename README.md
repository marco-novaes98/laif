# LAIF

LAIF is a personal, local-first AI assistant that runs entirely on its owner's
own Mac. It reads the owner's own digital life (calendar, mail, messages) to help
them stay organized and automate personal routines.

It is a single-user, personal project. It is **not** a public service and does
not offer accounts to anyone else.

## Google data

With the owner's explicit authorization, LAIF uses the Google Calendar API to
read the owner's events and to create new events on the owner's behalf. See
[PRIVACY.md](PRIVACY.md) for details.
